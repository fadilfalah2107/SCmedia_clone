## Struktur Proyek

```
project/
├── css/
│   ├── font/ (font icon)
│   ├── plugin.css (library CSS)
│   └── style.css (style utama)
├── js/
│   ├── init.js (script utama)
│   ├── plugin.js (library JS)
│   └── jquery.js (library jQuery)
├── img/
│   ├── about/ (gambar profil)
│   ├── portfolio/ (gambar proyek)
│   ├── news/ (gambar berita)
│   └── testimonial/ (gambar testimoni)
├── modal/ (modal kontak)
└── index.html (halaman utama)
```

## Fitur Utama

- **Desain Responsif**: Tampilan yang optimal di berbagai perangkat.
- **Animasi CSS3**: Animasi yang halus untuk pengalaman pengguna yang menarik.
- **Form Kontak**: Formulir dengan validasi untuk menghubungi pemilik portofolio.
- **Portofolio Interaktif**: Menampilkan proyek-proyek kreatif dengan popup detail.
- **Efek Cursor Kustom**: Menambahkan pengalaman visual unik.
- **Preloader Animasi**: Animasi saat halaman dimuat.
- **Popup Video**: Menampilkan video dalam modal untuk proyek tertentu.
- **Testimoni Teman**: Feedback dari teman-teman tentang karya yang dibuat.

- **Tools**:
